# 泰语学习路线（目标：泰剧生肉 / 演出 / 旅游）

> 建立日期：2026-09-01 ｜ 2026-09-08 改版：主线改为《基础泰语》丛书（原 M0–M5 里程碑作废）
> 动机：看懂泰剧生肉、听懂在泰国看的演出、旅游自助交流。
> 状态以学习面板「学习路线」页为准（仓库根目录 `index.html`，可点按钮推进状态）；本表同步维护。
> 里程碑状态栏为模板示例，请各自维护自己的进度。

## 起点与优势（中文母语者）

- 完全零基础，但中文母语 = 自带声调听辨外挂（泰语 5 声调，听感像普通话/粤语的调）
- 泰语语法是奖励关：无变位、无复数、无时态，语序接近中文
- 大量潮汕话借词：ก๋วยเตี๋ยว（粿条）、เต้าหู้（豆腐）、บะหมี่（肉面）、ชา（茶）

## 核心策略（针对"听口为主"的目标定制）

1. **主线 = 《基础泰语》丛书**（共 4 册）。以书为纲推进语法和课文，面板（字母表/词库/手写板/文章学习）当练习场；各册课数按手上版本的目录。
2. **认读为主、手写板描红辅**。目标全是听口，不要求默写；但每个新词在手写板上描一遍，"看到不认识"的问题靠描红 + 同屏认读解决。
3. **泰文字幕是作弊器**。泰剧自带泰文字幕：中文字幕看剧情 → 泰文字幕对声音 → 关字幕生肉。学拼读 = 解锁泰文字幕模式。
4. **听力输入为王 + 沉浸线并行**。生肉是几百小时可懂输入喂出来的；泰剧泰文字幕 / 每月一首歌 / 每日 15 分钟是并行线，不占主线坑。

## 每日最低配额与防崩机制

- **每日 15 分钟保底**：打开 Anki 刷 5 张卡也算完成。保连续性 > 保强度。
- **每周最小输出**：每周至少 1 个能读出声/说出口的东西，哪怕一句。
- **兴趣队列**：想啃的泰剧/演出/歌写下来（可放 `notes/兴趣队列.md`），学不动时看一眼。
- **B0 悬崖预警**：字母和拼读规则是全程弃坑率最高的地方。难受是正常的，所有人都一样，熬到 B1 能读课文就豁然开朗。
- **进度可见**：每节课后在面板「学习记录」页打卡，或自己维护一份学习日志。

## 起始牌组使用说明（starter-deck.csv）

- 150 词，10 个类别：礼貌语/代词/疑问词/数字/旅游交通/旅游餐饮/泰剧动词/泰剧形容词/常用短句/娱乐演出
- **字段顺序**（分号分隔）：`类别;泰文;音标;中文;词性;例句`
- **导入 Anki**：文件 → 导入 → 选这个 csv → 字段分隔符选 `分号`（若选项里有"首行为表头"请勾选）→ 导入。若泰文乱码，编码手动选 UTF-8。
- 音标为近似 Paiboon 方案、按声调规则推导，**仅供辅助，以真人发音为准**。

### 音频方案（卡片没声音怎么办）

- **路径 A（推荐）：AwesomeTTS 插件批量加音频**
  1. Anki → 工具 → 插件 → 获取插件 → 浏览，搜索 `AwesomeTTS`（别信随机博客里的插件代码，直接搜名字最稳）→ 安装 → 重启
  2. 在浏览器里选中泰语牌组全部卡片 → 工具 → AwesomeTTS → 批量生成，语言选泰语（Google TTS 的泰语质量不错，声调准确）
  3. 以后从泰剧挖的新词，同样一键补音频——这条工作流在泰剧挖词阶段高频使用
- **路径 B：真人发音抽查**。对声调拿不准的词，去 thai-language.com 查该词听真人发音（网站逐词有录音）。
- **路径 C：怕折腾插件时**。入门阶段以 Ling / studythai（自带音频）为主线，Anki 留到泰剧挖词阶段再启用。
- 机器音的局限：TTS 声调准确但语调略机械；真实的语感靠泰剧和歌曲本身喂，牌组音频只负责"听准每个词"。
- **扩词工作流**：看剧遇到高频生词 → 让 AI 出卡片（泰文/音标/中文/例句）→ 追加进本 csv 重新导入。

## 学习面板（index.html）

双击仓库根目录的 `index.html` 用浏览器打开，六个标签页：

- **学习路线**：里程碑时间线（B0–RAW），点状态按钮可切换 未开始→进行中→已完成
- **学习记录**：打卡（日期+分钟数+内容），自动算连续天数和累计分钟，14 天柱状图；支持导出/导入 JSON 备份
- **词库**：150 词卡片，点 ▶ 播放发音，可标记"已掌握"
- **字母表**：44 辅音（按中 9/高 11/低 24 分组，附口诀与高低配对）+ 25 个元音式（基础短长对 + 复合元音），点任意卡片播放发音，随身速查
- **组字练习**（2026-09-14 加，参考 iOS ScriptPad 的组字玩法）：听音 → 点部件把音节拼回去（声母/元音/声调符/尾辅音四槽，实时组合预览）。4 个关卡（中辅音起步 → 短元音与尾音 → 声调符 → 五调对战）+ 🎲 随机演练（机器随机报"中辅音+元音+声调"配方，即 B0 验收式抽查）。答对过的音节记住不再出；判错只告诉"哪个槽不对"；看答案会讲部件位置和实际声调规则（活/死音节、辅音类别×声调符的对照）。进度存 localStorage，随打卡数据一起导出
- **每格字体变体**（2026-09-10 加）：每个辅音卡/元音行里，除大字（课本手写体 Mali）外还并排挂着同一个字母的**印刷带圈体 / 无圈体（手机 App 主流）/ 广告体**三种写法，绿/蓝/橙三色区分，学认读时顺带认全字体差异；右上角「🔠 每格字体变体」可关（偏好存 localStorage）。点卡片的弹窗里有四款字体的放大对照
- **发音已离线内嵌**：400+ 条发音（微软泰语神经语音 Premwadee）以 base64 打包在 `word-audio.js` / `art-audio.js` 中懒加载，**手机断网也能点 ▶ 出声**。若以后增删词条需重配音频，见下方"重配发音"

⚠️ 面板数据存在浏览器 localStorage 里（不随文件走）。换电脑/清缓存前先「导出数据」；里程碑状态变更后记得同步回本文件的进度表。

### 重配发音（增删词条后）

音频由 msedge-tts（语音 `th-TH-PremwadeeNeural`）预生成，转 base64 后打包进音频 js 文件懒加载。增删词条后新词默认没有声音（会回退到网络/本地语音）；要补的话，用 msedge-tts 生成新词条的 mp3 → base64 → 追加进 `word-audio.js` 的映射表即可。
